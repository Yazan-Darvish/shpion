# Шпион

Игра для компании на одном телефоне. Все игроки, кроме шпиона, знают локацию и свою роль. Задавайте друг другу вопросы и вычислите шпиона, пока он не догадался, где вы.

**Играть:** https://yazan-darvish.github.io/shpion/

## Как играть

1. Все, кроме шпиона, получают одну и ту же локацию и свою роль в ней. Шпион не знает ничего.
2. Игроки по очереди задают друг другу вопросы о локации — так, чтобы свои поняли, а шпион нет.
3. Ответивший задаёт следующий вопрос кому угодно, кроме того, кто только что спрашивал его.
4. Шпион может в любой момент раскрыться и назвать локацию: угадал — он победил.
5. Когда время выйдет (или раньше), голосуйте, кто шпион. Поймали — победа мирных, ошиблись — победа шпиона.

## Возможности

- 3–12 игроков, 1–2 шпиона (второй — от 5 игроков), раунд 3–15 минут.
- 65 локаций, у каждой 6–8 ролей, разбиты на темы: медицина, городская жизнь, путешествия, работа, отдых и развлечения, культура и наука, 18+.
- Перед раздачей можно выбрать «Все локации» (без 18+) или одну или несколько тем. Локации 18+ попадают в игру только при явном выборе этой темы.
- Во время раунда играет фоновая музыка в стиле нуар-джаз (генерируется прямо в браузере, кнопка «♪ Музыка» выключает её); в последнюю минуту темп ускоряется.
- Таймер не отстаёт в фоне, по окончании — звук и вибрация; экран не гаснет во время раунда.
- Светлая и тёмная тема, установка на главный экран, работает без интернета после первого открытия.
- Настройки и имена запоминаются на устройстве.

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Каркас страницы |
| `style.css` | Стили, темы через CSS-переменные |
| `app.js` | Экраны и логика игры |
| `locations.js` | Темы, локации и роли |
| `manifest.webmanifest`, `sw.js` | PWA: манифест и офлайн-кэш |
| `icon-192.png`, `icon-512.png` | Иконки |
| `tools/make-icons.js` | Генератор иконок (Node, без зависимостей) |

## Локальный запуск

Сборка не нужна. Достаточно любого статического сервера:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Обновление

После изменения файлов увеличьте `CACHE_VERSION` в `sw.js`, иначе у игроков останется закэшированная версия.

Иконки пересоздаются командой:

```bash
node tools/make-icons.js
```

## Публикация на GitHub Pages

Репозиторий `shpion` → Settings → Pages → Deploy from a branch → `main` / `(root)`.
